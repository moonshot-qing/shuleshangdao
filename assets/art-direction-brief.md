# 校园传播美术精修 · 2026-11-09

当前已接入的代码素材规格；不是待做功能清单。制作路径为原生 Canvas / SVG 像素绘制，沿用现有素材系统，没有引入位图、图片生成服务或第三方素材。

## 视觉目标

暖色校园纸本、深墨单格轮廓、左上侧亮面、同一高度的肩线与脚底。人物先靠帽型、肩宽、发型和随身物件区分，再看颜色；状态不能覆盖服装类别。代表样式为戴帽、挂相机的营销号及持证据夹、穿衬衣的辅导员，两者与身份选择共用源帧。

类别衣色直接取 simulation.js 的 TYPES.color，与群聊名牌一致。人物肤色 #f0c9a5 / 阴影 #cc9677、头发 #544743 / 亮面 #796052、墨色 #30323b、纸白 #fffaf0。红 #d95c66 表示相信，绿 #34846b 表示核实；头顶分别绘制感叹号和勾形标记。衣色不随状态变化。

## 技术尺寸与接入

| 家族 | 源规格 | 实际用途 |
| --- | --- | --- |
| 八类人物 | 18×24 逻辑格，输出透明 36×48 Canvas；脚底逻辑 y=23 | 网络约24×32（手机已知人物）至30×39（桌面）；未听说人物缩为70%并降低不透明度，选择后可看放大详情 |
| 人物状态 / 姿态 | 3种传播状态×2种姿态×8类=48个缓存帧 | 发言后1100ms、实际状态变化后650ms抬手机；无额外漂移或待机抖动 |
| 身份肖像 | 64×56 Canvas，复用36×48人物 | 桌面128×112，手机96×84；肩线与脚底固定 |
| 卡牌插画 | 24×24 SVG逻辑格，透明、硬边 | 手牌48×48，矮屏24×24；融合48×48；详情复用同源图 |
| 场景缩略图 | 64×32 SVG逻辑格 | 桌面96×48，手机64×32 |
| 开场校园 | 600×190逻辑场景，1200×380 Canvas | 原面板内等比缩放；舞台/图书馆/超市各有对应建筑 |
| 结算小景 | 64×48逻辑格，128×96 Canvas | 桌面128×96，手机64×48；目标达成才盖金色印记 |

Canvas 禁用 imageSmoothing；SVG 使用 crispEdges；DOM 肖像用 image-rendering:pixelated。网络随视口缩放，实际尺寸不是所有设备上的逻辑格整数倍，已用桌面、手机实际截图检查。所有素材没有碰撞体、没有输入区域，交互仍属于现有按钮和人物选择。

## 细节分配

- 人物最多保留一件主道具：背包 / 相机 / 控制面板 / 书本眼镜 / 工牌 / 指向手臂 / 证据夹 / 手机星章。尺寸较小时优先看剪影，不为每个角色添加漂浮装饰。
- 卡牌以具体物件表达作用：热搜是手机与火苗，控评是带限制标记的对话框，反转是双向箭头与文稿，冷处理是通知与雪花，辟谣是证据与核实章。
- 校园层次：低饱和教学楼与树冠在后，场景建筑居中，人物与红绿派送在前。自行车、长椅、告示板用于建立校园语境；主对局仍显示关系网络。
- 网络网格降对比；矮屏四社群横向展开，修正原先上下边界冲突造成的单行堆叠。布局和提示只修改表现，不回写节点或传播状态。

## 动效与跨局

动作只接现有群聊、真实状态变化。speakingUntil 属于 visuals，与表现时钟绑定，暂停与后台不推进；减少动态模式使用静止姿态。startGame 通过 buildVisuals 重建所有人物动作计时；不消耗模拟随机数。

## 产物与验收范围

来源、许可、锚点、变体见 art-manifest.json。原生图鉴及四视口的开局、身份、对局、详情、融合、结算截图由 scripts/preview_art.py 输出到 test-results/art-review/。该脚本使用固定种子和强制结算的视觉样例，结算截图不证明自然流程或平衡。

当前已做 Chromium 五视口基础回归和三视口专项交互，查看桌面与手机截图；未做真实设备 / Safari 或玩家审美测试。美术完成情况不等于卡牌已平衡。
