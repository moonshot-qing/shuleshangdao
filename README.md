# 谣言瘟疫 · Rumor Plague

> 把一条谣言投进模拟校园社交网络，看它像瘟疫一样扩散——你是舆论场的操盘手。

一款零依赖、单页面的**传染病式谣言传播模拟游戏**。原生 JavaScript + Canvas 实现，参考 eBoy 的像素插画设计语言：统一像素网格、有限色板、模块化像素角色。

## 玩法

1. **选剧本开局**：新手局 / 进阶局 / 地狱局，三种初始条件（流量、公信力、关注度、谣言重要性各不相同）
2. **选难度与目标**：休闲 / 标准 / 大师三档难度；可预设目标结局，达成 +15 评分
3. **经营舆论**：信谣节点产出**流量**，流量购买卡牌；卡牌改变传播参数，但也推高**官方关注度**与**封号风险**
4. **随机性与不确定**：人群分波次不均匀刷入、随机事件流、二选一紧急事件弹窗、随机牌库抽卡（有保底）

### 五种结局

| 结局 | 达成条件 |
|---|---|
| 🔥 全网皆知 | 超过 55% 在线人口同时信谣并保持积累 50 帧（0.31 天） |
| 🧊 被扼杀在摇篮里 | 早期（峰值 <25%）彻底扑灭 |
| 🌪 反转后二次爆发 | 辟谣翻车 / 反转剧本触发舆论反转，二次波峰 ≥50% |
| 🎭 娱乐化消解 | 传遍全网（知晓 ≥50%）但没人信（信服 ≤12%），峰值不超过 55% |
| 🍃 悄然平息 / 🕯 不了了之 | 兜底结局 |

### 卡牌与传播学模型

16 张卡牌，每张绑定一个传播学概念（★普通 / ★★稀有 / ★★★史诗）：

- 🔥 加热搜（议程显著性）· 🤖 买水军（两级传播）· 📢 官方辟谣 · 🧊 冷处理（遗忘曲线）
- 🗣 控评（沉默的螺旋）· 📊 刷量 · 💉 群体接种（McGuire 接种理论）· 🔗 弱连接渗透（Granovetter）
- 🤝 大V公关 · 🎯 关键节点（Rogers 创新扩散）· 📰 议程设置（McCombs）· 🍉 转发抽奖
- 🎙 校园电台（使用与满足）· 🕵 反黑调查 · 🎬 反转剧本 · 🚨 辟谣热搜

### 8 类传播主体

大V（高传播枢纽）、营销号、吃瓜群众、辟谣bot、理中客、**群主**（社区中继）、**杠精**（围攻评论区压制辟谣）、**辅导员**（无视沉默的螺旋强力澄清；一旦信谣全校震动）。

## 特色机制

- **信息粒子**：每次传播/澄清都生成像素小球沿社交边飞行，抵达才结算——因果可视化
- **渐进浮现**：开局只有公众人物在线，群众随"听说"逐渐浮现，未浮现的节点与连线不可见
- **动态人群**：其余同学分 5-9 个随机波次、随机时刻涌入，每局的人口结构都不同
- **沉默的螺旋**：信谣率越高，清醒者越不敢发声，后期辟谣乏力
- **官方关注度 / 封号风险**：无脑堆热度会引来官方强制辟谣——若谣言已扩散过半，官方也会翻车

## 运行

无需构建、无任何依赖：

```bash
# 方式一：直接双击 index.html

# 方式二：本地服务器（推荐）
python -m http.server 8765
# 打开 http://localhost:8765
```

## 技术栈

- 原生 JavaScript（ES6+）、Canvas 2D、零依赖、单文件逻辑（game.js ~1600 行）
- 力导向布局（每帧物理模拟）、SIR 变体传播模型、像素精灵预渲染（字符串矩阵 → offscreen canvas）
