# 谣言瘟疫 · 看见信息的一生

一则校园消息，在转述与核实之间流动。选择传谣者或辟谣者，与相反阵营的人机打一场几分钟的卡牌对抗。

保留原项目的纸色、像素人物、社交网络与硬描边，增加原创像素校园开场、阵营交锋、卡牌说明、融牌、音效与传播复盘。原有分数及 S/A/B/C 等级保留，和阵营胜负分别呈现。

## 直接运行

游戏零运行时依赖，无需构建。双击 `index.html`，或在项目目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

访问 <http://127.0.0.1:8765>。

## 怎么玩

1. 选择音乐节、图书馆或超市事件，再选择传谣者或辟谣者。
2. 看红色转述与绿色核实怎样沿连接抵达人物。听说不等于相信，证据保护有时限。
3. 点卡牌看完整说明，使用明确的出牌按钮。初手包含行动、应对与资源牌，同名牌共用冷却。
4. 两张同等级牌可融合，先选保留的主牌再选消耗的辅牌。I→II 花 30 资源，II→III 花 45 资源，最高 III。
5. 强化牌在本局保留，冷却后可重复使用；费用随等级增加。可以形成核心牌，但融合会消耗资源和手牌选择。
6. 等待传播自然收束，查看阵营胜负、传播评分、曲线和关键时刻。可换身份或重玩同一网络。

常规参考约三分钟，完整流程优先；进行中的传播与反转会有收尾窗口。支持暂停、1/2/4×速度、网络缩放、触屏人物详情、键盘主要操作与减少动态效果。说明和融合面板里也能暂停思考。

传播动态恢复原版8类人物41条对白、5类自动随机事件和5类可选择突发：有营销号带节奏、同学吃瓜、bot贴核实，也有群主和辅导员接话。人物带像素头像、社群与回复关系，核实后可以改口；阶段统计默认展开。考试周、现身说法、外媒搬运、截图与玩梗都会实际改变传播，详见 [校园内容说明](CAMPUS_CONTENT.md)。手机可展开右下角“传播动态”回看。

传谣方在结算时让在线相信率达到 35% 即达成目标，辟谣方争取低于 35%。峰值不直接截断对局。评分沿用结局公式及 S/A/B/C，达成阵营目标另加 15 分，最高 100。评分和胜负衡量不同内容，详情可展开查看。

## 人机怎么行动

人机使用自己的资源、手牌与同名冷却。标准/大师对手使用公开局势的短时反事实试算，比较三条独立模拟中的牌效与费用，优先建立传播、核实关键人物或积攒资源，并利用热搜/水军、冷处理/辟谣的组合。它不读取对方手牌，不使用真实未来随机结果。大师反应更快，休闲给出更多思考空间。

复杂的长期意图系统仍是保留项，本版没有大模型服务或联网对手。

## 原版传播公式

保留并实际使用 `R=i×a`、沿连接的传播概率、沉默的螺旋、自然遗忘、公信力辟谣与传播状态。点击“传播指标 → 查看传播公式”，可以看到当前参数、接触概率及哪些卡牌正在改变它们；卡牌和人物详情也能看到对应理论与传播力。公式关系、原版出处及对抗参数校准见 [传播模型说明](PROPAGATION_MODEL.md)。

## 美术与声音

八类像素人物沿用并精修原资源，增加持手机姿态、证据保护标记、分组与传播路径层次。开场校园、16 个卡牌像素符号与所有反馈均由代码绘制，不加载外部美术素材。

音效用 Web Audio 合成，在点击开始后激活。顶部声音设置可静音、调整音量并保存；暂停/后台停止当前声音，恢复不补播。

## 开发验证

开发验证使用 Node、Python Playwright 和 Chromium/Chrome；它们不是游戏运行依赖。

```powershell
node --check game.js
node --check simulation.js
node scripts/verify_model.cjs
node scripts/verify_campus.cjs
node scripts/balance.cjs
python scripts/verify_experience.py
python scripts/verify_experience.py --demo
```

浏览器脚本自带临时服务器。`--demo` 额外录制真实计时的 4× 完整对局，`--demo-only` 只录实跑；录像依赖 Playwright 的 FFmpeg，可用 `python -m playwright install ffmpeg` 安装。结果和截图写入 Git 忽略的 `test-results/`。
